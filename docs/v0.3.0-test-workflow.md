**Version:** 1.0.0
**Date:** 2026-02-04
**Status:** Draft — Pending Implementation
**Feature Under Test:** Blog Posts CRUD

---

## Overview

This document specifies the end-to-end workflow for testing the v0.3.0 Agent Agency architecture. The test validates:

1. Dev-Manager orchestration
2. Context-Manager RAG integration
3. Worker agent scaffolding
4. Code review workflow
5. Test creation workflow

---

## Test Feature

**Feature:** Blog Posts CRUD (Create, Read, Update, Delete)

**Scope:**
- Database migration for posts table
- Eloquent Model with basic structure
- CRUD Controller with method stubs
- RESTful route definitions
- Blade view templates (blank business logic)
- Feature test scaffold

**Not Included (User Implements):**
- Controller business logic
- Form validation rules
- Model relationships
- View content/payload
- Test assertions and factory data

## Step-by-Step Execution

### Step 1: User Initiates Request

```
User: "Create a blog posts CRUD feature"
```

### Step 2: Dev-Manager Planning

```
Dev-Manager actions:
1. Analyze request → detects MVC pattern
2. Build task graph (see above)
3. Spawn agents sequentially
4. Wait for completion
5. Consolidate reports
6. Deliver to user
```

### Step 3: Worker Agent Spawning

```
Dev-Manager spawns @fullstack-dev for Task 1 & 2
```

### Step 4: Context-Manager Query (Mandatory)

```
@fullstack-dev calls @context-manager:

QUERY: "Laravel conventions for blog posts CRUD, migration structure, 
        controller patterns, route conventions, Blade view structure"

CONTEXT NEEDED: all
```

### Step 5: Context-Manager Response

```
@context-manager queries RAG → returns:

1. MIGRATION CONVENTIONS:
   - Filename: YYYY_MM_DD_HHMMSS_create_posts_table.php
   - Table name: posts (plural, lowercase)
   - Columns: id, title, content, author_id, published_at, 
             created_at, updated_at
   - use Schema::create with Blueprint

2. MODEL CONVENTIONS:
   - Class name: Post (singular, PascalCase)
   - Table: posts (plural)
   - $fillable: ['title', 'content', 'author_id', 'published_at']
   - $casts: ['published_at' => 'datetime']
   - No relationships in scaffold

3. CONTROLLER CONVENTIONS:
   - php artisan make:controller PostController --resource
   - Methods: index, create, store, show, edit, update, destroy
   - Return types: view() or redirect()
   - Blank business logic (user implements)

4. ROUTE CONVENTIONS:
   - Route::resource('posts', PostController::class)
   - Named routes: posts.index, posts.create, etc.

5. BLADE VIEW STRUCTURE:
   - resources/views/posts/index.blade.php
   - resources/views/posts/create.blade.php
   - resources/views/posts/edit.blade.php
   - resources/views/posts/show.blade.php
   - Blank content (user implements)

6. TEST STRUCTURE:
   - tests/Feature/PostsTest.php
   - Blank test methods (user implements assertions)
```
